# Stylesheets

Compiled CSS for the theme, organised into `base/` (variables, resets, utilities), `layout/` (regions, grid, page layout), `components/` (UI component styles), and `theme/` (editor/filter styling). Each `*.css` is generated from its `*.pcss.css` PostCSS source via `yarn theme:build` — edit the `.pcss.css`, never the `.css`.
